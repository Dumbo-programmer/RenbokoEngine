Engine Docs

Overview

Renboko provides a small, pragmatic set of systems useful for 2D games:

  • Service Locator — register global services like `InputSystem`, `Renderer2D`, `PhysicsWorld`, and `AudioSystem` via `ServiceLocator`.
  • Scene System — `Scene` base type with lifecycle hooks: `Start`, `Update`, `FixedUpdate`, `Render`, and `OnUnload`.
  • Renderer — `Renderer2D` provides basic sprite drawing and text rendering with a `Camera2D` transform.
  • Asset Manager — `AssetManager` supports content pipeline loads and file fallback with caching and reference counting.
  • Physics — basic `Rigidbody2D`, `BoxCollider2D`, and `CircleCollider2D` with simple collision resolution.
  • UI — retained-mode UI elements (`UIButton`, `UISlider`, `UILabel`, etc.).

Initialization

Typical initialization happens inside `EngineGame.Initialize()` where systems are registered and `AssetManager.Init` is called.

Asset Loading

Use `AssetManager.AcquireTexture`, `AcquireFont`, `AcquireSound` for stable, cached loads. The engine tries ContentManager loads first, then falls back to filesystem streaming.
