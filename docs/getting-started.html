Getting Started

Prerequisites

  • .NET 8 SDK
  • MonoGame 3.8 SDK/runtime
  • Optional: Visual Studio 2022/2023, VS Code

Build and Run

dotnet build MainEngine\RenbokoWorkspace.sln
dotnet run --project DemoGame/DemoGame.csproj

Common issues

  • If you see ContentManager load errors, ensure the Content pipeline assets were built (MGCB) or use file-based fallbacks.
  • Registering services order matters: `Renderer2D` and `AssetManager.Init` should be available before scenes try to load assets.
